Install steps:

1. Copy the folder `audiobookshelf-addon-fixed` into your Home Assistant local add-ons directory.
2. In Home Assistant, go to Settings > Add-ons > Add-on Store.
3. Click the three-dot menu and choose Reload.
4. Open the Audiobookshelf add-on.
5. Click Build, then Start.
6. Open: http://YOUR_HOME_ASSISTANT_IP:13378

If you already installed an older version of this add-on:
- Stop it first
- Rebuild from this version
- Start it again
